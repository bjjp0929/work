# 林凰予作品集首頁

這是一個純 HTML / CSS / JavaScript 的單頁作品集首頁。

## 檔案
- `index.html`：網站內容
- `styles.css`：版面與響應式設計
- `script.js`：手機選單與滑入動畫

## 本機開啟
直接雙擊 `index.html` 即可預覽。

## 部署到 GitHub Pages
1. 建立新的 GitHub repository。
2. 上傳三個檔案。
3. 到 Settings → Pages。
4. Source 選擇 `Deploy from a branch`。
5. Branch 選擇 `main` 與 `/root`。
6. 儲存後等待網址產生。
